# videotex-ui

Kit d’interface React inspiré du Vidéotex français : grille de 40 × 25, mosaïques semi-graphiques, 8 couleurs, touches de fonction.

> Projet en cours de construction, dépôt privé. Rien n’est encore publié sur npm.
